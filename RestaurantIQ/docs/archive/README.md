# Documentation archive

This directory preserves historical project notes that are no longer part of the primary recruiter or operator reading path.

The sprint notes record what was understood at the time each change shipped. Later code and canonical documents may supersede individual claims. Use these notes for chronology and context, then verify current behavior against the implementation, tests, [`sharp-edges.md`](../sharp-edges.md), and [`known-limitations.md`](../known-limitations.md).
